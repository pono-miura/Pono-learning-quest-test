Pono Learning Quest v470｜読んだ・聞いたチェック（任意）

【追加したこと】
・漢字問題など、v466の「📖 1文ずつ」を開くと「✅ 読んだ・聞いたチェック」が表示されます。
・本人が「✓ この文を確認した」を押すと、今の文に印がつきます。音で聞いた文もチェックできます。
・「🧭 文の道しるべ（v469）」の番号にも ✓ がつき、後から読み直す文が分かります。
・同じボタンでもう一度チェックを外せます。「チェックを全部外す」も使えます。
・確認した文の数を表示します。ただし、理解度・読字能力の評価や点数には使いません。
・画面を閉じると印は消えます。端末には保存しません。

【更新方法】
1. 学習記録をv456のバックアップ機能で保存してください。
2. ZIPを展開してください。
3. index.html をGitHubの同じ名前のファイルへ上書きします。
4. app-v470.js と style-v470.css を同じ場所に追加します。
5. 以前の app-v***.js と style-v***.css は削除しないでください。
6. 公開ページを再読み込みし、対応する漢字問題 →「📖 1文ずつ」で確認してください。

【確認】
① 1文目の「この文を確認した」を押す → 1文目の番号に ✓ がつき「1 / 3」になる。
② 2文目へ移動し、そこにも印をつける →「2 / 3」になる。
③ 1文目へ戻す → チェックがついたまま。
④ チェックを外す／全部外す → 印と数が戻る。
⑤ 「問題にもどる」で閉じ、再度開く → 印は0件から始まる。

【大切なこと】
・これは読んだ／聞いたことを本人が確認する任意の機能です。文字を読む訓練の強制や採点ではありません。
・教材、回答、正誤判定、学習履歴、学習者設定、既存の読み上げ機能は変更しません。
・v466/v469の対象画面でのみ動作します。全教科への一括適用はしていません。
・この機能のチェック情報は保存・同期しません。
・音声読み上げ自体は端末／ブラウザーの機能に依存します。

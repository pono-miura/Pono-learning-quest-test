Pono Learning Quest v448｜小学4・5年生 漢字の文章学習・仕上げ22語

小4の18字、小5の4字に対して、文に合う言葉・言葉の意味の2問ずつ（44問）と、自分で短い文を考える活動（22語）を追加しました。
今回の22字は、v435～v444で形の手がかりを作成済み、かつv440/v445/v446/v447で文章学習を作成していなかった字です。
4年202字＋5年193字、計395字すべてに「一つ以上の言葉を使う文章学習」を用意しました。各字の読みの全種類や全熟語の網羅、書字習得を示すものではありません。

学習上の配慮
・書き取りは必須ではなく、口頭・文字入力・心の中での作文も可能です。
・音声、ゆっくり読み上げ、文字拡大、ヒント、3語・5語の短時間練習、誤答時の再挑戦、学習者別記録に対応。
・正答を「実際に書ける」とは評価しません。本人が入力した自由文の内容は保存しません。
・末/未、以上/以下など、混同しやすい言葉を補足します。

Androidの更新方法
1. 使っている学習フォルダー全体をバックアップします。
2. ZIPを展開して index.html を置き換えます。
3. app-v448.js と style-v448.css を既存ファイルと同じフォルダーへ追加します。
4. 以前のJS・CSSファイルを削除しないでください。
5. アプリのトップで「文章学習の仕上げ22語｜v448」を開いてください。

学習記録は端末内の保存です。別端末と自動同期しません。
Pono独自の文章・説明です。ミチムラ式の公式の唱え文は転載していません。

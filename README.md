# Pono Learning Quest v13 — 学年横断・自動調整 第1版

v12の機能を残したまま、算数に「本当に動く」学年横断ルートの第1版を追加しました。

## 今回の自動調整
- 在籍学年を開始位置の目安にする
- 算数で確認問題を実施
- 理解が不十分な場合、前提となる内容へ自動移動
- 前提内容を確認できたら、元の単元へ自動で戻す
- 学習した道すじを記録
- 保護者画面でも「必要な内容を確認しながら進んだ」経過を表示

試作の算数ルート:
小1 たし算 → 小2 九九 → 小3 わり算 → 小4 わり算の計算 → 小5 分数 → 小6 分数のかけ算

これは自動調整エンジンの第1版です。問題数は意図的に少なく、今後、文部科学省の現行学習指導要領に沿った単元グラフとPonoオリジナル問題を増やします。

注意:
GitHub Pages＋localStorageの試作です。本番の認証、クラウド同期、保護者アクセス制限は未実装です。

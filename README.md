# Pono Learning Quest v12

v11に「1日複数科目」と「お休み設定」を追加しました。

## 時間割
- 月〜金それぞれに複数の科目・単元を追加可能
- 「＋ 科目を追加」でその日の予定を増やせる
- 不要な予定は個別に削除
- 曜日ごとに「🌿 お休みにする」を設定
- お休みの日でも、本人が希望すれば自由学習は可能
- 子ども画面では複数の予定を「今日のおすすめ」として表示
- 予定は義務ではなく目安。全部終えなくても、予定より進んでもよい設計

注意:
現在はGitHub Pages＋localStorageの試作です。本番の複数端末同期、保護者のアクセス制限、実際の学年横断自動調整には認証・クラウドDB・本格問題バンクが必要です。

# Pono Learning Quest v14 — 統合基準版

v14は、これまで話し合った仕様を今後落とさないための基準版です。

## 今回、実装した内容
- 在籍学年と「学習開始の目安」を分離
- 学習開始の目安は小1〜小6から変更可能
- 算数の単元開始時に「説明から」「問題から」を選択
- ①まなぶ → ②一緒に → ③自分で
- 問題途中から説明へ戻れる
- 「わからない・説明を見る」
- 説明利用・一緒に確認した回数も学習過程として記録
- 学年横断の前提単元確認 → 元の単元へ戻る流れ
- 分数を上下＋横線の一般的な表示に変更
- 間違いメッセージが増殖しないよう修正
- v12の1日複数科目・お休み設定を継続

## 今後も保持する基準仕様
- 子ども：今日のおすすめは義務ではない。別教科、先へ進む、今日はここまでを選べる
- 保護者：本番では自分の子だけ。点数だけでなく学び方・成長・次のおすすめを表示
- 先生/Pono：全生徒一覧、個人詳細、時間割、学校の現在単元、個別A4/PDF
- 学校共有：既習内容への戻りを「遅れ」と扱わず、学習経過を自動文章化
- 記録：自力、説明、ヒント、読み上げ、わからない、時間、前提確認、後日の定着
- 国語：漢字＋読解。読字・書字負担に配慮
- 漢字の将来機能：読み、意味、形、部首・パーツ、書き順アニメーション、なぞり、語呂合わせ・イメージ、文中利用
- 算数：教科書で見慣れた数式表記
- 先生の時間割：複数科目、休み、先週コピー、おすすめ自動作成、個別調整
- 学年横断：理解確認 → 前提単元 → 元へ戻る → 発展 → 後日定着
- 将来：オンライン交流（Pono管理、少人数活動・作品共有等。子ども同士の無管理DMは想定しない）
- 本番：認証＋クラウドDB。保護者アクセス制御、複数端末同期

## 注意
現在はGitHub Pages＋localStorageの試作です。問題バンク、全単元グラフ、後日定着、認証・クラウド、オンライン交流は段階的に実装します。

- 国語：漢字＋読解。読字・書字負担に配慮

## v14.3 教材作成の共通ルール

新しい単元では、問題を解く前に「その単元で初めて覚える内容」を学べる説明を必ず用意する。

### ① まなぶ に含めるもの
- 新しく出てくる用語
- 用語の意味
- 公式
- 公式の読み方
- 記号の意味と読み方
- 最小限の具体例
- 必要に応じて図・視覚的説明
- その単元学年までに習う漢字を基準にした文章
- 未習漢字は原則ひらがな
- 学習上必要な専門用語は「漢字＋ふりがな」
- 読み上げに適した読みテキストも別に持つ

### 子どもの選択
単元開始時に
1. 📖 説明からはじめる
2. 🚀 問題からやってみる
を選べる。

説明からの場合は「①まなぶ → ②一緒に → ③自分で」。
問題から始めても、途中で「説明を見る」「わからない・説明を見る」に戻れる。
説明利用はマイナス評価にしない。

### 全教科へ適用
算数だけでなく、国語・理科・社会・外国語活動／外国語にも適用する。
国語では新しい文法・漢字等、理科・社会では重要語句、外国語では新しい表現・意味・読み方を扱う。

### 長期不登校への配慮
授業を受けていない期間があっても、説明から学ぶことで単元を開始できる教材を目指す。
一方、家庭学習等で理解している子は説明を飛ばせる。

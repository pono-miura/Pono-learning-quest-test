# Pono Learning Quest v8
v7を土台にした試作版です。

追加した考え方:
- 学年固定ではなく、理解状況に応じて「確認→定着→発展」へ
- 説明・ヒント・読み上げ・「わからない」も学び方として記録
- 保護者画面に「今週のようす」「学び方の変化」「次のおすすめ」
- 先生画面に学校提出用の自動下書き
- 必要な既習内容へ戻った学習も「遅れ」ではなく学び直しの経過として扱う
- 個別印刷/PDF

重要:
これはGitHub Pages用のローカル保存試作です。複数端末での同期・安全な実名運用・本当の個別適応には、次段階で認証とクラウドDBが必要です。
現時点の問題バンクは3年生相当の試作中心です。

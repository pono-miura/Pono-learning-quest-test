# Pono Learning Quest v11
v10に保護者画面の見える化を追加した試作版です。

保護者画面:
- 今週の取り組み回数・時間
- どんなふうに学べているか
- 予定からの広がり
- できるようになってきたこと
- 次のおすすめ
- 「予定どおり」を評価せず、進む・定着・既習内容の確認を学びの経過として表示

子ども:
- 在籍学年は開始の目安
- 今日のおすすめは予定であって固定ではない
- 理解できれば「もう少し進む」
- 必要なら定着・基礎確認
- いつでも「今日はここまで」

先生/Pono:
- 時間割
- 現在地・達成状況
- 学校提出用の自動下書き

重要:
現状はGitHub Pages＋localStorageの試作です。実際の保護者アクセス制限はまだありません。
本番では認証・クラウドDB・保護者とstudent_idの紐付けによって、自分の子の情報だけを表示します。

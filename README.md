# Pono Learning v3 — 3年算数「わり算」完全動作試作

今回の目的は「実際の問題結果から、戻る・進む・定着確認」を一つの単元で最後まで動かすことです。

実装：
- 最初の理解度確認（九九／わり算の意味／計算／文章題）
- 結果から開始位置を自動選択
- 九九・かけ算への学び直し
- わり算の意味 → 文章題
- 単元ミニテスト5問
- 80%以上なら3日後の定着チェックを予定
- 定着チェック3問
- ヒント回数・読み上げ回数・学習時間・経過を保存
- 先生画面／学校共有記録
- 印刷・PDF保存
- 正解時のみ短い音

注意：
これは機能検証用です。実在児童の個人情報を公開GitHub Pagesへ入力しないでください。
本番運用にはログイン認証・クラウド保存・権限管理が必要です。

- 間違いメッセージが増殖しないよう修正

## 今後も保持する基準仕様
- 子ども：今日のおすすめは義務ではない。別教科、先へ進む、今日はここまでを選べる
- 保護者：本番では自分の子だけ。点数だけでなく学び方・成長・次のおすすめを表示
- 先生/Pono：全生徒一覧、個人詳細、時間割、学校の現在単元、個別A4/PDF
- 学校共有：既習内容への戻りを「遅れ」と扱わず、学習経過を自動文章化
- 記録：自力、説明、ヒント、読み上げ、わからない、時間、前提確認、後日の定着
- 国語：漢字＋読解。読字・書字負担に配慮
- 漢字の将来機能：読み、意味、形、部首・パーツ、書き順アニメーション、なぞり、語呂合わせ・イメージ、文中利用
- 算数：教科書で見慣れた数式表記
- 先生の時間割：複数科目、休み、先週コピー、おすすめ自動作成、個別調整
- 学年横断：理解確認 → 前提単元 → 元へ戻る → 発展 → 後日定着
- 将来：オンライン交流（Pono管理、少人数活動・作品共有等。子ども同士の無管理DMは想定しない）
- 本番：認証＋クラウドDB。保護者アクセス制御、複数端末同期

## v14.3 教材作成の共通ルール

新しい単元では、問題を解く前に「その単元で初めて覚える内容」を学べる説明を必ず用意する。

### ① まなぶ に含めるもの
- 新しく出てくる用語
- 用語の意味
- 公式
- 公式の読み方
- 記号の意味と読み方
- 最小限の具体例
- 必要に応じて図・視覚的説明
- その単元学年までに習う漢字を基準にした文章
- 未習漢字は原則ひらがな
- 学習上必要な専門用語は「漢字＋ふりがな」
- 読み上げに適した読みテキストも別に持つ

### 子どもの選択
単元開始時に
1. 📖 説明からはじめる
2. 🚀 問題からやってみる
を選べる。

説明からの場合は「①まなぶ → ②一緒に → ③自分で」。
問題から始めても、途中で「説明を見る」「わからない・説明を見る」に戻れる。
説明利用はマイナス評価にしない。

### 全教科へ適用
算数だけでなく、国語・理科・社会・外国語活動／外国語にも適用する。
国語では新しい文法・漢字等、理科・社会では重要語句、外国語では新しい表現・意味・読み方を扱う。

### 長期不登校への配慮
授業を受けていない期間があっても、説明から学ぶことで単元を開始できる教材を目指す。
一方、家庭学習等で理解している子は説明を飛ばせる。


## v14.5 学校共有用・学習報告書の基準

Pono Learning Quest から作成する書類は、出席扱いの申請・報告書とは分け、
純粋に「どのように学習したか」を学校へ共有するための学習報告書とする。
出席扱いについては学校指定の用紙を使用し、本システムでは判定・申請を行わない。

### 学習セッションごとに自動記録する項目
- 実施年月日
- 開始時刻・終了時刻
- 実学習時間
- 教科
- 学習した内容の学年相当
- 単元名
- 取り組んだ内容
- 問題数・正答数
- 自力で解けた内容
- 説明を確認した内容
- 「一緒に」を利用した内容
- ヒント利用
- 読み上げ・ふりがな等の学習方法
- 必要に応じて確認した既習単元
- 元の単元へ戻った経過
- 現在の理解状況
- 数日後の定着確認
- 次に取り組む内容

### 単元の状態
「未確認／説明から／練習中／自力でできた／定着確認済み」で確認できるようにする。
単純な正答率だけで理解を判断しない。

### 学校共有用A4学習報告書
児童生徒1名・指定期間ごとに作成できるようにする。
- 対象期間
- 学習日時と学習時間
- 教科・学年相当・単元
- 学習内容
- どこまで終了したか
- 理解の様子
- 使用した学習方法
- 既習内容の確認と現在の単元へのつながり
- 定着状況
- 次の学習計画
- Ponoコメント

### 月ごとのまとめ
- 今月終了した単元
- 学習中の単元
- 定着確認済みの単元
を一覧で確認できるようにする。

学校指定の出席扱い用紙とは連動させず、必要に応じて学校が学習状況を把握するための補足資料として使用できる設計とする。

## v16.0 算数・学年横断単元マップ拡張
文部科学省の現行小学校学習指導要領（算数）の系統性を基準に、Ponoオリジナル問題で算数の前提単元ルートを拡張。
試作実装単元：
- 1年：かずのしくみ／たし算・ひき算の意味
- 2年：たし算・ひき算の筆算／かけ算・九九
- 3年：かけ算の筆算／わり算の意味
- 4年：わり算の筆算／分数の意味と大きさ
- 5年：分数のたし算・ひき算／小数のかけ算・わり算／割合
- 6年：分数のかけ算／分数のわり算／比
各単元に prerequisite（前提単元）を設定し、理解状況に応じて前へ戻り、確認後に元の単元へ戻る土台を拡張。
※これは全算数単元の完成版ではなく、学年横断エンジンを育てるための主要系統の第一段階。

## v16.2 算数単元マップ拡張（図形・測定・データ）
現行学習指導要領の算数4領域（数と計算／図形／測定または変化と関係／データの活用）を踏まえ、単元選択画面を拡張。
- 1年：かたち、長さ・かさ・広さくらべ
- 2年：長さ、時こくと時間、三角形と四角形、表とグラフ
- 3年：重さ、時間計算、円と球・三角形、表と棒グラフ
- 4年：角、面積、垂直・平行と四角形、折れ線グラフと表
- 5年：三角形・四角形の面積、体積、合同・多角形、平均と帯/円グラフ
- 6年：円の面積、角柱・円柱の体積、拡大図と縮図、データの調べ方
Ponoオリジナル問題を使用。今後、各単元の説明・一緒に・定着確認を深める。


## v16.3 ①まなぶ・②一緒に 本格化
- 算数の各単元で「意味→具体例→一緒に→自分で」の流れを統一。
- 面積・体積・円の面積では公式と読み方を明示。
- 分数系では分子・分母・約分のことば確認を継続。
- 説明の読み上げ、一緒に読むボタンを追加。
- 未習単元でも入口に立てる説明を優先し、既習の子は従来どおり問題から開始可能。
- 現段階では主要単元に専用説明、その他は単元問題を使った共通説明。今後、全単元を専用ミニ授業へ深める。


## v16.4 問題タイプ・つまずきの見分け
- 算数の問題に「理解確認／基本／文章・場面／少し応用」の学習タイプ表示を追加。
- 現在3問構成の単元では「理解確認→基本→文章・場面」と表示。
- 誤答時に、問題文・場面の読み取りに関係する可能性がある問題と、計算・考え方を確認したい問題を分けて案内。
- 記録に errorKinds を保存し、将来の先生画面で「計算そのもの」か「文章・場面理解」かを見える化できる土台を追加。
- これは診断ではなく、次にどんな説明が役立つかを考えるための学習記録。
- 今後、各単元の問題数を増やす際に4タイプを十分な問題数で構成する。


## v16.5 モデル単元：6年「分数のかけ算」
Ponoの1単元の完成形を検討するため、6年「分数のかけ算」を先行して8問構成へ拡張。
- 🔎理解確認 2問
- ✏️基本 2問
- 💬文章・場面 2問
- 🌟少し応用 2問
- ①まなぶでは「ある量の何倍」「約分」「文章題の式」の考え方を追加。
- 問題はPonoオリジナル。
- 誤答時の「問題文・場面」／「計算・考え方」記録を継続。
- 後日の定着確認は、保存日時を使った再出題設計を次段階で実装予定。今回の版では未実装。


## v16.6 後日の定着確認
- 算数で90%以上だった単元を、学習から2〜14日後に「そろそろ定着確認」として子ども画面に表示。
- 元の単元から3問だけ再出題し、短時間で確認。
- 2/3以上で「定着確認済み」として新しい記録を保存し、元記録の状態も更新。
- 2/3未満なら「定着をもう一度確認」と記録し、①まなぶへ戻れる。
- これは能力判定ではなく「時間をあけても思い出せるか」を見る学習上の再確認。
- 現在はブラウザlocalStorageの日付を利用。将来クラウド化した際はユーザーごとの定着スケジュールへ移行する。

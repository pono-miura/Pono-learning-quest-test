# Pono Learning Quest v9
v8に、在籍学年を「開始の目安」として選ぶ画面と、本番の権限設計を明確化した試作版です。

- 小1〜小6の在籍学年を選択
- 学年は固定レベルではなく開始位置の目安
- 理解状況に応じて既習内容の確認→現在の学習→発展へつなぐ設計
- 保護者画面は「自分の子の学び」を前提に設計
- 先生は現在地・達成状況・提出用自動下書き
- 戻って学ぶことも努力・学び直しとして記録

注意:
現状はGitHub Pages＋localStorageの試作です。実際の保護者アクセス制限や複数端末同期は未実装です。
本番では認証・クラウドDB・role/student_idによるアクセス制御が必要です。
問題バンクはまだ試作用で、学年別の本格問題バンクと前提単元グラフは次段階です。

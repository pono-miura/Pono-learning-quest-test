Pono Learning Quest v422 / 小学5年生・英語

【更新するファイル】
index.html ／ app-v422.js ／ style-v422.css（3ファイル）

1. 更新前のアプリ一式を別の場所にコピーしてバックアップします。
2. ZIPをダウンロードし、Androidの「マイファイル」→「ダウンロード」で展開します。
3. 展開した index.html を、アプリが入っている場所の index.html と置き換えます。
4. app-v422.js と style-v422.css を、index.html と同じ場所に追加します。
5. app-v421.js までのファイルは削除しないでください。
6. アプリ内の「小学5年 英語｜18小単元」から学習します。

収録：9大単元18小単元、練習108問＋確認テスト180問＝288問。
まなぶ3ページ→いっしょに考える→練習6問→テスト10問。
英語の音声（速さ調整）、解説、間違い直し、学習記録保存に対応。
書く練習は任意で採点せず、読む・聞く・話す・書くの5領域を意識した補助教材です。
音声はAndroid等の端末の読み上げエンジンに依存します。
各学校の検定教科書とは単元の順序・表現が異なる場合があります。

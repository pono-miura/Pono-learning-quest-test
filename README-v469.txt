Pono Learning Quest v469｜文の道しるべ（今何文目？／番号で移動）

【追加したこと】
・「📖 1文ずつ」を開くと「ぜんぶで3文。いまは1文目だよ」と進みぐあいが表示されます。
・進行状況を棒グラフ（進みぐあいのバー）と番号で分かりやすく表示します。
・「1」「2」「3」などの番号を押すと、好きな文に戻ったり、読み直したりできます。
・番号を押したときは、v467/v468の読み上げを止めてから移動します。
・手動で「つぎの文／まえの文」を押した場合やv468の連続読みでも表示が追随します。

【更新するファイル】
1. 先にv456のバックアップ機能で学習記録を保存してください。
2. ZIPを展開して、index.htmlを同じ名前のファイルへ上書きします。
3. app-v469.js、style-v469.css をGitHubの同じフォルダに追加します。
4. 古い app-v***.js と style-v***.css は消さないでください。
5. index.html はv468とv469の読み込みを両方含んでいます。

【確認方法】
・漢字問題で「📖 1文ずつ」を開き、「🧭 いま、どこを読んでいるかな？」が出るか確認します。
・2文以上ある問題で、最後の番号を押して最後の文に移動し、1を押して最初の文に戻るか確認します。
・v468「つづけて聞く」を使った際、文の番号が進行に合わせて変わるか確認します。

【注意】
・今回の変更はv466の対応画面だけで有効です。すべての教科の問題が対象ではありません。
・教材本文、解答、採点、学習記録、個人情報の保存方法を変更しません。
・読み上げが動くかは端末とブラウザに依存します。番号移動は音声なしでも使えます。
・別端末への自動同期や学習者の認証機能は追加しません。

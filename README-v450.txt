Pono Learning Quest v450｜小学4・5年生 漢字395字の個別学習まとめ

【今回の追加内容】
・小学4年生202字・小学5年生193字（計395字）の学習状況を一覧にまとめます。
・v438で確認した「読む」「形が分かる」「手書き・代替方法」を別々に表示します。
・v440 / v445〜v448の「言葉・文の練習回数」、v449の「思い出し復習回数と次回予定日」を表示します。
・今日のおすすめ5字、復習日が来た字、ヒント・見直しが必要だった字、未確認の項目がある字、書字への配慮の記録がある字を見分けられます。
・漢字・読み・言葉の検索と詳細表示ができます。
・先生・保護者向けのまとめ画面と、学年別CSV出力に対応します。
・入力した自由文、先生のメモ、学習者名・学習者IDはCSVに含めません。
・今回の画面は旧記録の読み取り専用です。既存の評価・復習日を上書きしません。

【大切な点】
・「未確認」は「できない」と同じ意味ではありません。
・選択問題の正解は、漢字を手書きできることの証明ではありません。
・練習回数は習得字数や診断ではありません。必要に応じて先生が実際の状況を確かめてください。
・読み／形／書字は別々に見て、本人に合う回答方法を優先してください。
・新しい問題や新しい漢字は今回追加していません。既存の395字の学習を整理・活用する更新です。

【Androidでの更新方法】
1. 現在の学習フォルダーをバックアップしてください。
2. ZIPを展開してください。
3. index.html を現在の index.html に置き換えてください。
4. app-v450.js と style-v450.css を既存ファイルと同じフォルダーに追加してください。
5. 以前の app-v***.js / style-v***.css は削除しないでください。
6. トップから「漢字の学習まとめ｜v450」を開いてください。

【注意】
・この機能は v449 の app-v449.js が正常に読み込まれていることを前提としています。
・学習履歴は現在の端末内に保存されています。自動同期や自動通知はありません。
・CSVファイルには学習記録が含まれます。共有先と保存場所を確認して扱ってください。
・公式ミチムラ式の唱え文やカードの転載ではなく、Pono独自の言葉による学習の支援機能です。
・実際の公開環境で更新後の動作確認をお願いします。

Pono Learning Quest v455 — 共用端末の学習者確認と返却チェック

■ この更新で追加すること
・先生が学習者IDと端末の状態を確認してからv454を開く2項目チェック
・途中の学習がある場合の表示と、別の学習者の画面が使用中の場合の注意
・先生への返却確認・一時停止確認の記録
・選択中の学習者だけを対象にした確認記録のCSV保存
・小学4・5年生の選択をv454へ引き継ぐ

■ 更新手順（Androidでも同じです）
1. 現在使用中のアプリフォルダーをバックアップしてください。
2. ZIPを展開してください。
3. ZIP内の index.html をアプリフォルダーの index.html と置き換えます。
4. app-v455.js と style-v455.css を同じフォルダーに追加します。
5. app-v454.js、style-v454.cssおよび以前のファイルは削除しないでください。
6. トップ画面に「共用端末の学習者確認 v455」が表示されることを確認します。

■ 注意事項
・このZIPに含まれるのは更新用4ファイルだけです。旧バージョンのJS/CSSも必要です。
・この機能は画面の取り違えを減らすための補助です。認証・パスワード保護・暗号化ではありません。
・端末のロックなどの管理が必要です。学習者IDは先生の確認画面には表示されます。
・確認記録はブラウザーのlocalStorageに学習者別で保存され、別端末には同期されません。
・CSVファイルには氏名と学習者IDを含めません。確認日時、学年、確認内容のみです。
・v438の読み・形・書字の評価、v449の復習履歴、v454の学習記録を変更しません。
・学習途中の保存を返却確認しても、途中データは消しません。

Pono Learning Quest v464 / 使ってみて確認・改善点の記録

【更新方法】
1. ZIP を解凍します。
2. index.html は以前のものと置き換えます。
3. app-v464.js と style-v464.css は同じフォルダに追加します。
4. 旧バージョンの app-v***.js / style-v***.css は削除しないでください。
5. 更新前には v456 のバックアップ機能で学習記録を保存することを推奨します。

【追加したこと】
・先生の学習者確認、試用前の3項目チェック
・実際の操作6場面を「未確認/自分でできた/支援が役立った/困った」に分けて記録
・本人の感想（任意）、今回試した方法（任意）、先生の観察メモ
・使いにくい点を「場面」「優先度」「対応状況」で記録、対応後に変更
・匿名集計CSV：学習者名・学習者ID・試用日・自由記述を含まない
・v461先生用ホームへのショートカット、v463操作ガイドへの導線

【注意】
・先生用確認はパスワード認証ではありません。
・試用記録は現在選択している学習者の端末内にのみ保存されます。
・入力には氏名や診断名などの個人情報を書かないでください。
・この画面は学習の採点や、障害の診断・評価を行うものではありません。
・共有時は、小規模集計でも個人を推測されないか確認してください。
・別端末へは自動同期されません。端末内のデータを定期的にバックアップしてください。

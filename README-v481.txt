【今回改善した点】
・英語：I like ～などの語句の入れ替え、8単元の基本表現、複数問の練習、10問まとめテスト、音声と発音練習（ブラウザの対応状況による）
・理科：「物の燃え方と空気」の3ページ説明、実験の条件・結果を扱う6問練習、10問確認テスト
・国語：「主張と根拠」の本文（根拠1、根拠2を表示）、段階別ヒント、記述回答、飛ばす
・算数：6年生の20問テストで、間違えた問題を解説後に入力して解き直す。初回結果はそのまま残す。既存の答え合わせ画面に追加
・社会：正解まで解き直した基礎・標準・応用練習について「初回 → 解き直し後」を併記

【重要事項】
この更新は新しい教材と補助機能を追加するもので、すべての旧教材の構成を変更するものではありません。
小学6年の国語・英語・理科は、単元画面に表示される「この詳しい教材を開く」から改善版に入ります。
算数と社会は既存の学習画面を補助します。
学習記録は以前と同じ端末保存で、端末間での自動同期や安全な個別認証はまだありません。
公開版はGitHub登録前の段階ではv480です。旧教材ファイルを削除せず、試験利用は仮IDで行ってください。

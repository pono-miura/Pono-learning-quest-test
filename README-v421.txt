Pono Learning Quest v421 / 小学4年生 外国語活動

更新方法（Androidでも同じ）
1. このZIPをダウンロードして「マイファイル」のダウンロードから展開します。
2. 既存のアプリにある index.html を新しいファイルで置き換えます。
3. app-v421.js と style-v421.css を同じ場所に追加します。
4. 以前の app-v***.js と style-v***.css は削除しないでください。
5. 4年生→英語（外国語活動）の画面、または全学年メニューから「小学4年 英語｜18小単元」を開きます。

収録：9大単元・18小単元。各小単元はまなぶ3ページ・いっしょに話す・練習6問・テスト10問。合計288問。
音声は端末の読み上げ機能に依存するため、利用端末で実際に再生を確認してください。
文字の読み書きや発音自体は自動採点しません。
学習記録はこれまでと同じ仕組みを利用します。保存には学習者が選ばれている必要があります。

公開中のアプリのバックアップを残してから更新してください。

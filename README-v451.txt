Pono Learning Quest v451｜小学4・5年生 漢字395字：学び方と支援方法の提案

追加内容
・v449/v450の記録を参考に、復習予定、ヒント、未確認の項目からおすすめの漢字を提示。
・小学4年202字、小学5年193字に対応。1回3字または5字。
・音声、部品、意味と例文、思い出しの4種類から本人が選択。いつでも変更できます。
・一字ずつヒントや答えを確かめ、「取り組めた／ヒントが役立った／別の方法」を記録。
・先生や保護者が試した方法の傾向を確認できます。
・v438の読み／形／書字の確認結果、およびv449の復習予定は上書きしません。
・今回、新しい漢字や選択式問題を増やすものではありません。

大切な注意点
・「未確認」は苦手・できないことを意味しません。
・「自分で取り組めた」は本人の振り返りであり、正答率や手書き能力の判定ではありません。
・固定的な「視覚型・聴覚型」分類ではありません。本人の意思を優先してください。
・保存データは端末と学習者ごとに区別し、他端末との同期はありません。
・学習者未選択時は体験用の記録になります。
・音声は端末に音声合成機能がある場合に使えます。

Androidでの更新方法
1. まず現在の学習フォルダーをバックアップします。
2. ZIPを展開します。
3. index.html を現在の index.html に置き換えます。
4. app-v451.js と style-v451.css を同じフォルダーに追加します。
5. 以前のJS/CSSや保存記録は削除しません。
6. Pono Learning Quest のトップに現れる「自分に合う学び方 v451」を開きます。

必要な旧ファイル：app-v449.js、app-v450.js

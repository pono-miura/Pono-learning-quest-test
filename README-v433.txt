Pono Learning Quest v433｜国語の記述問題・部分点ふり返り

【更新方法】
1. 更新前のフォルダーを必ずバックアップしてください。
2. ZIPの index.html を従来のファイルと同じ場所に上書き。
3. app-v433.js と style-v433.css を追加してください。
4. 以前の app-v...js / style-v...css は削除しないでください。

【内容】
小学4年10問・小学5年10問、合計20問のオリジナル短文記述練習。
文章を読み、答えを入力するとキーワード各2点と文末1点、5点満点で参考点を表示。
記述の正否を完全に判定する機能ではありません。言いかえや説明の自然さは必ず先生・大人が確認し、必要なら点数を修正してください。
確認後の点数のみ既存の学習記録に保存します。入力した文章は記録に保存しません。
記述評価は学校や問題によって異なります。必ず授業・試験の実際の採点基準を優先してください。

【注意】
・このZIP単体では、過去の学習アプリ全体は動きません。従来の全ファイルが必要です。
・音声再生は端末・ブラウザーの音声合成機能に依存します。
・公開中のアプリでは更新後の確認が必要です。

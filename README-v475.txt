Pono Learning Quest v475 — 在籍学年から学び、必要に応じて別学年で学び直す

1. 開くと、まず登録済みの在籍学年の教科選択が表示されます。
2. 国語・算数など教科を選び、単元を選びます。
3. 「🌱 つまずいたら、前の学年を確認」を押すと、単元名の関連語を使って以前の学年の教材候補を案内します。
4. 以前の学年の教材で確認した後、在籍学年側のもとの単元に戻るボタンを表示します。
5. 自分で別の学年を選んでも、登録されている在籍学年は変えません。
6. 「以前の教材一覧を見る」から従来の長い一覧へ戻れます。

注意：学び直しの候補は単元名の関連語から選んだ例であり、採点結果を使った自動判定・診断ではありません。
理解度に応じた完全自動の戻り学習は試用観察後の拡張対象です。
学習内容・採点・履歴・ID・個人情報を変更しません。端末間同期・本人認証は未対応です。
選択した教材の途中で別教材へ移動すると、保存前の途中経過は引き継げない場合があります。

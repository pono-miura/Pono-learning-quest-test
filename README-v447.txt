Pono Learning Quest v447｜小学4・5年生・漢字の意味と文脈（Android簡単更新版）

新規：小学4年生50語、小学5年生50語、合計100語。v443で部品学習を作った漢字を題材に、文に合う言葉と意味を選ぶ2種類の問題＝計200問、さらに自分の文を考える活動を追加。
v440・v445・v446の題材と漢字の重複はありません。これで4・5年生の配当漢字395字中、延べ373字が「言葉と文で学ぶ」練習に対応します（習得済みという意味ではありません）。

配慮：書き取りは必須にしません。音声読み上げ、ゆっくり音声、文字拡大、ヒント、3語・5語からの練習、学習者別の進捗を搭載しています。自由入力文そのものは保存しません。

更新方法：
1. 現在の学習フォルダーをバックアップ。
2. ZIPを展開し、index.htmlを置き換え。
3. app-v447.js と style-v447.css を同じフォルダーへ追加。
4. 以前のJS・CSSファイルは残してください。
5. Pono Learning Questのホームから「漢字100語の文脈練習 v447」を開いてください。

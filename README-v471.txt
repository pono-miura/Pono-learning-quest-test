Pono Learning Quest v471｜読みガイドを使いやすく（スマートフォン向け）

【今回の改善】
・v466「📖 1文ずつ」を開くと、問題文のすぐ下に基本操作をまとめて表示します。
・基本操作：1文を聞く／つづけて聞く／音を止める／確認チェック／前の文／次の文／問題にもどる。
・「⚙️ くわしい設定・番号で移動」を押すと、従来の速度選択、文番号移動、チェック解除、細かい操作が開きます。
・不要なときは詳細を閉じたまま学習できます。設定と機能は従来どおりです。
・v470の確認チェックは本人が任意に付け、画面を閉じると消えます。

【GitHubでの更新】
1. 学習記録をv456のバックアップ機能で保存します。
2. ZIPを解凍します。
3. index.html を同名ファイルと上書きします。
4. app-v471.js / style-v471.css を既存のファイルと同じ場所に追加します。
5. v466〜v470を含む過去のJavaScript/CSSは削除しません。
6. 再読み込みし、漢字問題の「📖 1文ずつ」を開いて確認します。

【動作確認】
・問題文の下に「よく使う操作」が2列で表示される。
・「次の文」「前の文」で文が移動し、ボタンの有効/無効が切り替わる。
・「✓ 読んだ・聞いた」を押すと「チェック済み」になり、もう一度押すと外せる。
・「⚙️ くわしい設定・番号で移動」で従来の速度変更や番号移動を使える。
・「問題にもどる」で読みガイドが閉じる。

【ご注意】
・この更新はv466に対応する漢字問題などの読みガイドだけに適用します。すべての教材に一括適用しません。
・教材、回答、採点、学習履歴、端末内の設定、学習者IDは変更しません。
・読み上げは端末/ブラウザーの音声機能に依存します。
・実際の子どもの利用時には、文字の大きさとボタンの見やすさを確認してください。

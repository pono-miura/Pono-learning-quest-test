Pono Learning Quest v480 — 詳しい教材の入口・学習の道すじ

【公開サイト用】
1. 既存のGitHub上の学習記録・教材ファイルは削除しないでください。
2. このZIPの index.html をリポジトリ直下の index.html に上書きします。
3. app-v480.js と style-v480.css を同じ直下に追加します。
4. index.html では v479 のメニュー読み込みを外し、v480 を読み込むようにしています。
   旧版の app-v479.js/style-v479.css はリポジトリに残して問題ありません。
5. 公開サイトを開き直し、子ども→在籍学年→教科→詳しい教材→小単元→学習を確認してください。
6. 「学ぶ」「一緒に考える」「練習」「テスト」は元の教材側の機能です。
   ふりかえりの形式と問題数は、既存教材ごとに異なります。

【変更しない内容】
・教材の問題文、正解判定、採点、学習記録の保存方法
・保護者用、Pono管理者用の画面
・学校への出席扱い申請・通所報告書（アプリ学習報告とは別）

【変更した内容】
・子ども用入口を一本化（v475/v477/v478/v479の重複表示を避けます）
・詳しい教材（小学3〜5年の一部など）をトップの学年・教科から選べます
・詳細教材にある小単元を表示し、可能な場合は直接その小単元を開きます
・単元に入った後に学習の道すじを表示、固定ボタンの重なりをなくします
・在籍学年を変えずに他学年の学習内容を見ることができます

【試験利用の注意】
・詳しい教材が存在しない学年・教科は従来版の単元に接続します。
・一部の教材は、小単元の自動移動ではなく、元の教材の一覧から選ぶ形です。
・端末間の履歴同期と利用者ごとのログイン認証は未実装です。
・実名や診断名等は入力せず、仮IDで試してください。
・Android、タブレット、PCすべての実機動作は未検証です。
・学習結果は終了時点まで保存されない場合があります。途中で戻るときは注意してください。

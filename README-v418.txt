Pono Learning Quest v418｜小学4年 社会「5大単元・20小単元」

追加教材：
【1】 わたしたちの都道府県
  1-1 日本の都道府県と県庁所在地
  1-2 山や川・土地の広がり
  1-3 人口・交通と土地の使われ方
  1-4 山梨県の特色を調べよう
【2】 住みよいくらしを支える水とごみ
  2-1 水のもとと水源
  2-2 浄水場と水道のしくみ
  2-3 ごみの分別と減量
  2-4 ごみの収集・処理・再利用
【3】 自然災害からくらしを守る
  3-1 地震と建物の備え
  3-2 大雨・川の増水・土砂災害
  3-3 ハザードマップと避難
  3-4 地域で協力する防災
【4】 伝統・文化と先人たち
  4-1 地域の祭りと年中行事
  4-2 文化財と伝統工芸
  4-3 水路をつくった先人の働き
  4-4 文化を守り次の世代へ
【5】 特色ある地域と人々のくらし
  5-1 特色ある農業と産地
  5-2 地域のものづくりと技術
  5-3 自然を生かす観光と環境
  5-4 国際交流とこれからの地域

各小単元：まなぶ（説明3ページ）・いっしょに考える・練習6問・単元テスト10問
合計20小単元、練習120問、単元テスト200問、320問。

主な機能：
・大単元を選ぶ → 小単元を選ぶ → まなぶ → いっしょに考える → 練習 → 単元テスト
・日本語読み上げ／ゆっくり読み上げ、ヒント的な図解
・練習は1問ずつ解説、テストは最後に採点
・答えと解説、間違えた問題の解き直し
・既存プロフィールと学習記録への追記（既存のprofile/records/saveが機能する場合）

更新：
1. 既存のアプリ一式を必ずバックアップしてください。
2. このZIPのindex.htmlで既存index.htmlを置き換えてください。
3. app-v418.jsおよびstyle-v418.cssを同じ場所に追加してください。
4. 旧バージョンのJS/CSSを削除しないでください。今回のZIPは増分更新であり単体では全教材は動作しません。
5. 社会→小学4年の画面を開き「小学4年 社会 小単元を開く」を選んでください。
6. 新しい画面が見えない場合は更新（再読み込み）をしてください。

注意：
・学習用の仮想的な図・一般化した例を含みます。地域の水源・ごみ分別・避難先等は、最新の自治体資料で必ず確認してください。
・教科書会社によって単元の名前や順番が異なる場合があります。
・旧版の学習記録を削除する処理はありません。保存・同期は既存の仕組みに依存します。
・問題文と解説は独自に作成し、教科書本文を転載していません。
・水道水の仕組みや防災の方法は地域や状況によって異なります。

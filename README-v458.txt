Pono Learning Quest v458｜個別学習レポート（先生の確認用）

【更新】
1. 更新前のフォルダーと学習記録をバックアップしてください。
2. ZIP内のindex.htmlで既存のindex.htmlを置き換えます。
3. app-v458.js / style-v458.cssを同じフォルダーに追加します。
4. 既存のapp-v*.js、style-v*.cssを削除しないでください。
5. 再読み込みして「個別レポートを作る」から開きます。

【機能】
・小学4年202字／5年193字の漢字記録をもとに学校向け・保護者向けのレポート下書きを作ります。
・期間内の学習記録と、全期間の最新の先生確認結果を区別します。
・個別に「取り組めたこと」「本人の言葉」「役立った支援」「次の小さな目標」「連携先への確認」を追記できます。
・本人や共有先を確認してからコピー、テキスト保存、A4印刷（対応環境ならPDF保存）できます。
・下書きの保存は任意で、保存した内容は端末内のlocalStorageにのみ記録されます。
・以前の学習記録を書き換えません。

【注意】
・学校所定の出席認定書類や診断書ではありません。
・書字の記録がないことを「書けない」とみなしません。
・先生用画面にアクセス認証はありません。共用端末では管理に注意してください。
・印刷/PDF保存、クリップボードの動作はブラウザーの許可・設定に左右されます。
・個人情報を含む下書きやバックアップファイルは安全に保管してください。
・このZIPだけでは動作しません。以前の教材ファイルがすべて同じフォルダーに必要です。

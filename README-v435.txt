Pono Learning Quest v435｜書字の負担をおさえる「部品と言葉で覚える漢字」

【更新に必要なファイル】index.html / app-v435.js / style-v435.css

【更新方法】
1. 既存の学習記録とアプリのファイルをバックアップ。
2. index.html を置き換える。
3. app-v435.js と style-v435.css を同じ階層へ追加。
4. v434以前のファイルは削除しない。インターネット公開環境へ更新後は画面を再読み込み。

【今回の内容】
・小学4年 34字、小学5年 39字の合計73字に、Ponoが独自に書いた部品の説明文を用意。
・漢字 → 熟語／例語 → 左右／上下／囲みの部品説明 → 4択で部品を組み合わせる → 見ないで想起 → 自己チェック。
・音声（日本語の読み上げ・ゆっくり）付き。端末によって音声が出ないことがあります。
・書くことを強制しません。自分で確認したい場合のみ、空中で指を動かしたり紙に一度書く選択肢があります。
・正解数や書字の正確性を測るテストではなく、「部品の形の理解」を支援する教材です。
・先生と保護者が、学習者に合う言い方へ変更し保存できます。保存内容はブラウザー内／学習者別であり端末間同期はありません。
・v434 の395字の配当漢字一覧・練習状況はそのまま。v435で扱う漢字は一部のみです。

【参考にした学習の考え方】
ミチムラ式漢字学習法の「形を部品として捉え、音声化して理解する」「繰り返しの書写から始めない」という考え方を参考にしました。
この教材内の言い方はPonoによる独自の記述であり、ミチムラ式の公式唱え文・商品内容を転載したものではありません。ミチムラ式の公式教材・商品ではありません。
参考： https://kanji.cloud/studymethod/method-features/ 

【注意】書字困難への有効性・適性には個人差があります。読み書き困難にあわせて、音声入力、キーボード入力、文字選択、紙に書かない評価の方法も継続してください。

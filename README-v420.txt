Pono Learning Quest v420 更新方法（小学3年・外国語活動）

1. ZIPをダウンロードして展開します（Androidでは「マイファイル」→「ダウンロード」→「展開」）。
2. これまでアプリを配置している場所の index.html を、このZIPの index.html に置き換えます。
3. app-v420.js と style-v420.css を同じ場所に追加します。
4. v419以前のファイルは絶対に削除しないでください。旧版を残して読み込む仕組みです。
5. 更新前には、学習記録をバックアップしておくことをおすすめします。

内容：小学3年の外国語活動／4大単元16小単元／練習96問＋確認160問＝256問。
英語音声は端末の音声合成機能を利用します。英語の音声が出ない機種では文字表示でも進められます。
※聞く・話す練習が中心です。選択問題の点数は、実際の発音や会話力を直接評価するものではありません。

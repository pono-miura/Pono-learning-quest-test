Pono Learning Quest v444 — Androidかんたん更新用

小学4年生18字・小学5年生4字、合計22字を追加しました。
部品や線の形を言葉で確認し、読み・部品・思い出しの3問を学びます（計66問）。
これまでのv435（73字）、v441〜v443（300字）と合わせ、小学4年生202字・5年生193字＝395字すべてに形の学習がそろいました。

更新手順
1. いまのフォルダーをバックアップしてください。
2. ZIPを展開し、index.html を前の同名ファイルと置き換えます。
3. app-v444.js と style-v444.css を index.html と同じ場所に追加します。
4. 以前の app-v*.js、style-v*.css は絶対に削除しないでください。

学習の流れ：漢字・部品（形）を見る→読みを選ぶ→形の手がかりを選ぶ→漢字を思い出す→振り返る。
3字または5字の少量練習、文字拡大、読み上げ、復習予定、学習者別記録に対応。
書き取りは必須ではありません。選択問題の正解が、書けることを意味するわけではありません。

漢字の分け方は厳密な字源・筆順ではなく、形を覚えるための説明です。
ミチムラ式の考え方を参考にしていますが、公式カードの唱え文は転載していません。

データは同じ端末の localStorage に保存されます。別端末との自動同期はありません。
含まれるファイル：index.html / app-v444.js / style-v444.css / README-v444.txt

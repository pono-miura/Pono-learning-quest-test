Pono Learning Quest v456（学習記録のバックアップ・復元）
================================================

【更新】
1. このZIPを展開してください。
2. 今使っているアプリ一式を念のためコピーし、バックアップしてください。
3. index.html を上書きしてください。
4. app-v456.js と style-v456.css を同じフォルダーに追加してください。
5. v455までのJS/CSSや既存の学習記録は削除しないでください。

【新機能】
先生用「学習記録のバックアップ v456」から、
・端末内の localStorage（このアプリが開いている保存領域）の内容をJSON保存
・保存したJSONを選び、数・重複を確認した後に復元
・既存の記録は残し、ない項目だけを追加（標準）
・必要な場合だけ、二つの確認後に同じ項目を上書き
・保存失敗時は変更を元に戻す処理
を行えます。

【重要】
・バックアップファイルには学習者IDや学習記録などの個人情報が含まれる場合があります。
  学校・施設の管理方針に従い、他人が閲覧できない場所に保管してください。
・JSONの内容は暗号化されていません。公開・共有リンクには置かないでください。
・「ファイルを選ぶ」だけではデータは書き換わりません。
・このアプリが開かれている保存領域の localStorage を対象にします。
  その保存領域の他のキーも含まれることがあります。
・v454の「子ども用画面が使用中」の一時情報（pono454-active-device）はバックアップ対象外です。
・IndexedDB、ブラウザー内の別オリジン・他の端末、アプリのプログラムそのものは含みません。
・端末やブラウザーにより file:// のデータ保存場所が分かれることがあります。
  同じ保存領域で起動していること、記録が表示されることをご確認ください。
・復元後はアプリを再読み込みし、先生用の一覧で記録が見えるか確かめてください。
・元の端末の記録は、移行先で正しく読めることを確認するまで消さないでください。
・本機能はインターネット送信や自動クラウド同期を行いません。

【テスト】
ローカルのスマートフォン相当ブラウザー環境でバックアップ生成・JSONの検査・
欠けた項目だけの復元・確認を経た上書き・破損ファイル拒否・使用中の復元禁止を検査しています。
実際の各端末と保存設定での確認は更新後に必要です。

Pono Learning Quest v442 — Android更新用

今回は小学4年生50字＋5年生50字の、言葉と部品による漢字学習を新たに追加しました。
v435の73字、v441の100字と合わせて計273字です。v434の4・5年生配当漢字全395字の一覧はそのまま残ります。

更新の手順：
1. ZIPファイルを展開します。
2. index.html は元のファイルと置き換えます。
3. app-v442.js と style-v442.css を元のファイルと同じ場所に追加してください。
4. 過去の app-v*.js、style-v*.css は削除しないでください。更新前にはフォルダーのバックアップをおすすめします。

学習：4年生50字、5年生50字。3字または5字ずつ「部品を知る→読みを選ぶ→部品を選ぶ→文字を選んで思い出す」。書き取りは必須にしていません。
音声機能は使用する端末の音声合成に依存します。読み上げなしでも学習できます。
復習日と取り組みは学習者ごとに端末内の localStorage に保存されます（クラウドには同期されません）。
この練習で正解しても、自力で書けることを示すものではありません。評価はv438の読み・形・書字の記録と分けています。

部品の捉え方は覚えるための補助で、字体によって見え方が異なる場合があります。唱え方はPono独自に制作し、ミチムラ式公式の唱え文は転載していません。

内容：index.html、app-v442.js、style-v442.css、README-v442.txt

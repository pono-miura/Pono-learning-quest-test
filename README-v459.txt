Pono Learning Quest v459 更新手順（Android・簡単更新）

【新しい機能】
小学4・5年生の漢字395字について、先生が1〜5字の小さな目標を設定し、実際に試した学習方法や本人の様子を記録できます。
・目標を作る：対象漢字、初めに試す方法、1週／2週／1か月後の見直し時期
・振り返る：本人が選んだ方法、ヒント、休憩、負担の様子を、観察した事実をもとに記録
・見直す：方法や次の見直し日を変更、継続／一区切り／調整／休止を選択
・先生用の文章をテキスト保存

【更新方法】
1. 更新前に、今使っているファイルと学習記録のバックアップを作成してください。v456のバックアップ機能も利用できます。
2. ZIPを展開します。
3. 既存の index.html をこのZIP内の index.html に置き換えます。
4. app-v459.js と style-v459.css を、これまでの app-v458.js 等と同じフォルダに追加します。
5. 古い app-v*.js / style-v*.css は消さないでください。
6. Pono Learning Quest を開き、学習者を選択して「🌱 学習後の目標と支援の見直し v459」を開いてください。

【大切な注意】
・既存のv438の読み・形・書字評価、v449の復習記録、v458のレポートは上書きしません。
・新しい目標・観察は同じ端末内のlocalStorageに、学習者IDごとに保存します。
・入力した観察文は端末内に残り、テキスト書き出しにも含まれます。共有先を確認し、個人情報を適切に管理してください。
・現在選択した学習者の記録だけを表示します。子ども用の学習画面が使用中は開けません。
・先生用画面のパスワード認証はありません。共用端末の画面ロックなどを併用してください。
・この機能は漢字の習得・障害・発達を自動判定するものではありません。「未確認」は「できない」ではありません。
・端末間の自動同期や自動通知はありません。個人情報を含むバックアップは安全に保管してください。

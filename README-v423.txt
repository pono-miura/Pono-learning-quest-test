3. app-v423.js と style-v423.css を index.html と同じ場所に追加してください。
4. 旧 app-vXXX.js と style-vXXX.css は削除しないでください。
5. 公開ページを更新し、「教材の完成状況を確認」「小学4年の算数へ」を確認してください。

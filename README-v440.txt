Pono Learning Quest v440（Android向けシンプル更新）

今回の追加：小学4年34語＋小学5年39語＝計73語。
各語について「文に合う言葉」「言葉の意味」の2問、計146問。
3段階目に口頭・心の中・文字入力で「自分の文を考える」活動を用意しました。
この73語はv435からの既存の漢字を文章の中で使う練習です。新しい73字を追加したものではありません。

更新手順
1. 安全のため、今使っているPono Learning Questフォルダをコピーしてバックアップ。
2. ZIPを展開する。
3. index.html を以前の index.html と置き換える。
4. app-v440.js と style-v440.css を、従来の app-v*.js / style-v*.css と同じフォルダへ追加する。
5. app-v439.js や style-v439.css を含む古いファイルは削除しない。
6. index.html を開き、トップ画面の「言葉と文の練習｜v440」から動作を確認する。

機能
・1語ずつ、またはおすすめ3語／5語。単語の分野別表示。
・「文に合う言葉を選ぶ」→「意味を確かめる」→「自分の文を考える」。
・4択、間違えたときのやり直し、音声読み上げ、音声の速さ調整、文字拡大。
・自由文の入力は任意。入力した文章は端末内の練習記録に保存しない。
・「考えた」「例文を参考にした」「今日はここまで」の状態を保存。
・v437の復習予定、v438の個別記録、v439の練習履歴を参考におすすめ順を変更。
・学習記録はこの端末内・学習者ごと。別の端末には自動同期されない。

注意
・4択の正解は「文や意味を選べた」ことの記録であり、漢字が書けるかの判定ではありません。
・作文内容はAIによる添削・点数化をしていません。表現のよさなどは支援者が確認してください。
・v435の公式外の独自教材を使っています。外部の漢字教材や唱え文は転載していません。
・古いファイル・データを消すと、以前の教材が動かなくなることがあります。
・今回の確認は独立したブラウザーテスト環境で行ったもので、公開環境での動作保証ではありません。

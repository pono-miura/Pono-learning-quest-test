Pono Learning Quest v426（小学5年 算数：基礎5分野・10小単元）

このZIPは「追加更新用」の差分です。単独では旧教材は動きません。

1. 公開済みのアプリのファイル一式をバックアップしてください。
2. ZIPを展開して index.html を既存ファイルと置き換えます。
3. app-v426.js と style-v426.css を同じ階層に追加します。
4. v425以前のファイルを削除しないでください。
5. 再読み込み後、小学5年算数の入口から v426 の10小単元を選んでください。

収録内容：整数と小数・体積・小数のかけ算・小数のわり算・整数の性質。
練習60問、確認テスト100問、合計160問。

既存の記録を消す操作はありません。学習者プロフィールが選択された状態のみ記録を追記します。
実際の公開環境で、更新後の画面表示をご確認ください。

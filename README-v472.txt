Pono Learning Quest v472｜「👀 文に集中して読む」

【追加内容】
・v466～v471の「📖 1文ずつ」画面に「👀 文に集中して読む」を追加。
・押すと説明や細かなボタンを一時的に隠し、1文と基本操作を中心に表示します。
・集中表示では「この文を聞く」「音を止める」「前の文」「次の文」「問題にもどる」が使えます。
・「↩ いつもの操作を表示」を押せば元の画面に戻ります。
・画面を閉じ、次に開くと通常表示から始まります。本人が使うかどうか選べます。

【GitHubでの更新】
1. 先にv456のバックアップ機能で大事な学習記録を保存してください。
2. ZIPを解凍します。
3. index.html をGitHubの同名ファイルと上書きします。
4. app-v472.js と style-v472.css を既存のファイルと同じ場所に追加します。
5. 古い app-v***.js と style-v***.css は削除しません。
6. 対応する漢字問題 →「📖 1文ずつ」を開き、「👀 文に集中して読む」を確認します。

【確認手順】
・集中表示にすると、読みガイドの説明と詳細設定が隠れ、本文と必要な操作が見える。
・前の文／次の文へ移動でき、1文目・最後では移動できないボタンが無効になる。
・「この文を聞く」「音を止める」を試す（実際の音声は端末とブラウザに依存）。
・「↩ いつもの操作を表示」で、v471のボタンと「⚙️ くわしい設定」が戻る。
・一度閉じ、もう一度開くと通常表示に戻っている。

【注意】
・既存の教材、回答、採点、学習記録、学習者ID、保存した読み上げ速度・表示設定は変更しません。
・チェックや進度などの情報は新しく保存しません。
・集中表示はv466「📖 1文ずつ」に対応する一部の問題だけで使えます。
・音声はAndroid端末やブラウザにより使えない場合があります。

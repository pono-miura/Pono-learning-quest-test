Pono Learning Quest v474：学年を選ぶ → 教科を選ぶ → 教材を選ぶ

【今回の改善】
子ども向けの最初の画面で「小学1〜6年」から学年を選び、次に国語・算数・理科・社会・英語・生活科を選びます。
その学年・教科に登録されている既存の教材カードだけを表示します。学年や教科は何度でも変更できます。
「以前の教材一覧を見る」から、今までの長い一覧にも入れます。

【更新】
学習履歴をv456でバックアップしてから以下をGitHubの同じフォルダに入れてください。
1. index.html（既存のファイルを上書き）
2. app-v474.js（新しく追加）
3. style-v474.css（新しく追加）
以前のapp-v***.jsやstyle-v***.cssは削除しないでください。

【重要】
・v473の次に入れるのは今回の「学年別入口 v474」です。前に作成した未公開の「音声連動v474」のZIPとは混ぜないでください。
・学習内容、単元の採点方法、学習者ID、記録の保存内容には変更を加えていません。
・入口の単元一覧は既存のカードの表記（学年・教科）を読み取って表示します。学年が書かれていない共通教材などは漏れることがあるため、「以前の一覧を見る」も残しています。
・先生用機能は従来の画面に残ります。
・学習記録は端末内に保存され、端末間の自動同期はまだありません。
・本番の認証はまだありません。試験運用時は実名や診断名を入力しないでください。

【確認】
公開ページを再読み込み → 小学5年 → 算数 → 割合などの教材が出る → 単元を押すと既存の教材画面が開く。

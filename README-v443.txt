Pono Learning Quest v443 — Androidかんたん更新用

小学4年生50字、小学5年生50字の部品学習を新たに追加しました。今回100字、3問ずつ計300問です。
既存の部品学習273字と合わせて373字（4・5年生の配当漢字395字中）。残り22字です。

更新手順
1. 作業前にフォルダーをバックアップしてください。
2. ZIPを展開し、index.html を前の同名ファイルと置き換えます。
3. app-v443.js と style-v443.css を index.html と同じ場所に追加します。
4. 以前の app-v*.js / style-v*.css は削除しないでください。

学習は「漢字と部品を見る→読みを選ぶ→部品の組み合わせを選ぶ→思い出す→振り返る」です。
3字か5字の少量練習、文字拡大、読み上げ、復習予定、学習者別記録に対応。
書き取りは必須にしていません。正解したことは、自力で書けることを意味しません。

部品の分け方は形を覚えるための学習上の手がかりであり、字体や漢字の成り立ちの厳密な説明ではありません。
ミチムラ式の考え方を参考にしていますが、公式の唱え文は転載していません。
記録は同じ端末の localStorage に保存され、別端末に自動同期されません。

含まれるファイル：index.html / app-v443.js / style-v443.css / README-v443.txt

Pono Learning Quest v465 — 読みやすさ・押しやすさの個別設定

■ 今回の追加
・文字サイズ「ふつう・大きめ・とても大きい」
・行間「ふつう・ゆったり」
・ボタン「ふつう・大きめ」
・文字と背景「ふつう・くっきり」
・子どもの学習中に「🔎 表示」から変更できます。
・設定は同じ端末内の、選択中の学習者IDごとに保存します。
・既存の主要な漢字学習画面（v454の子ども用画面、v463の操作ガイド、v441〜v449の一部）で有効です。
・採点、個別評価、学習履歴を書き換えません。

■ Androidでの更新
1. 大切な学習記録は、先にv456のバックアップ機能で保存してください。
2. このZIPを展開してください。
3. index.html を現在のファイルと置き換えてください。
4. app-v465.js、style-v465.css を、これまでのapp-v***.jsとstyle-v***.cssのある同じフォルダーへ追加してください。
5. 古いJS/CSSは削除しないでください。
6. Pono Learning Questを開き、「v465｜見やすい文字とボタン」から設定を確認してください。

■ ご注意
・v465は文字の見やすさを調整する機能で、学習の診断・書字能力の判定はしません。
・以前の学習画面のすべての表示要素に設定が反映されるわけではありません。
・音声読み上げ速度は、従来の学習画面側で調整してください。
・学習者を選ばない体験モードの設定は保存されません。
・学習者IDが変わると、その子に保存された表示設定へ切り替わります。
・別の端末への自動同期はありません。
・テスト用ブラウザーでは表示・保存・切り替えを確認しましたが、実際の配布・公開環境でも確認してください。

Pono Learning Quest v437　更新手順
--------------------------------
今回の内容：小4・小5の漢字73字を、書き取り必須にせず、思い出す練習で復習する機能。

【更新に必要なファイル】
  index.html （前回のものと置き換え）
  app-v437.js （新規追加）
  style-v437.css （新規追加）

1. 現在公開しているファイル一式をバックアップしてください。
2. ZIPを展開してください。
3. 現在のアプリと同じフォルダーに app-v437.js と style-v437.css を追加してください。
4. 同じフォルダーの index.html だけ新しいもので上書きしてください。
5. app-v436.js、app-v435.js、その他過去のJS・CSSは削除しないでください。
6. アプリを開き、ホーム画面の「漢字の思い出し復習｜v437」から動作確認してください。

【学習の仕組み】
・今日が復習日になっている字から最大5字、または新しい漢字を3字、または任意の1字を選びます。
・最初は字を隠し、例語を一部空欄にして思い出します。
・必要なら「部品のヒント」を見て、答えを確認します。
・自力で思い出せた場合：次回まで1日→3日→7日→14日を目安に間隔を延ばします。
・ヒントが必要だった場合：1日後を次回の目安とします。
・v436の部品学習の記録があれば、「一度触れた字」として最短翌日から初回の思い出し復習の候補にします。

【注意】
・これは自動通知や外部からのリマインドを行う機能ではありません。アプリを開くと復習日を確認できます。
・復習の評価は本人の自己申告です。正しく書けること、漢字を完全に習得したことを意味しません。
・過去のv434〜v436の学習記録を削除しません。v437の記録は選択中の学習者ごとに端末内に保存します。
・端末を変えても自動同期しません。ブラウザーのデータを削除すると記録を失う可能性があります。
・v435の部品説明を元に作ったPono独自の復習です。ミチムラ式の公式カード・唱え文は転載していません。

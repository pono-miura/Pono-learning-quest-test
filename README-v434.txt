Pono Learning Quest v434｜漢字の全字点検と読み練習

更新ファイル：index.html / app-v434.js / style-v434.css

＜更新手順＞
1. 現在のファイルをバックアップしてください。
2. index.html を既存のものと置き換えます。
3. app-v434.js と style-v434.css を同じフォルダへ追加します。
4. 以前の v222〜v433 のJS/CSSは削除しないでください。
5. ブラウザーを再読み込みして「漢字の全字チェック v434」を開きます。

＜内容＞
小学4年 202字、小学5年 193字、合計395字の学年別チェックリスト。
「読める／練習中／未確認」の管理、各学年50語の読み練習（各10問×5）。
追加した読み練習は合計100問です。全字の読み・書き取りテストではありません。
1字ずつの学習状況は端末のブラウザー保存領域に、学習者ID別で保存します。
ブラウザーのデータを消したり、別端末に移すと、この点検状態は引き継がれません。
読み練習の結果は既存の学習者が選択されていれば学習記録にも保存を試みます。
読みの自動判定は収録した練習語についてのみです。

漢字一覧の根拠：平成29年告示学習指導要領・学年別漢字配当表
https://jp-cos.github.io/821/0000100000000
配当字一覧照合：https://www.hatosan.com/utc/kanji.html

※ 今回の全字点検は「全395字すべての読み・書き・筆順まで指導できる」という意味ではありません。
※ 続編で未整備の字の具体例・読み方・書き取りや紛らわしい漢字を増やせます。

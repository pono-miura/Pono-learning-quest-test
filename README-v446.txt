Pono Learning Quest v446｜小4・小5 漢字を文の中で使う学習（Android簡単更新版）

新規：4年生50語・5年生50語、合計100語。v442で部品学習を追加した100字を対象に、文に合う言葉・言葉の意味の選択問題計200問と、自分の文を考える活動を追加しました。
v440の73字、v445の100字の対象漢字とは重複しません。文章で使う対象は延べ273字（395字中）。

特徴：書かずに取り組めます。音声、ゆっくり読み上げ、文字拡大、3語・5語ずつの練習、例文、ヒント、学習記録を搭載。自由に入力した文章そのものは保存しません。「意味を選べた」と「書ける」は別の評価です。

更新方法：
1. 現在の学習フォルダーを必ずバックアップする。
2. ZIPを展開し、index.htmlを置き換える。
3. app-v446.jsとstyle-v446.cssを同じフォルダーに追加する。
4. 以前のJS・CSSファイルは削除せず残す。
5. アプリのトップから「新しい漢字の言葉練習 v446」を開く。

学習記録は端末に保存。別端末とは自動同期しません。データ消去に注意してください。
漢字学習の手がかりと例文はPono独自の教材です。ミチムラ式の公式の唱え文は転載していません。

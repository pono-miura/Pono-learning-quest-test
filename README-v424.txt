Pono Learning Quest v424 更新ガイド

【今回の追加】
小学4年生 算数 — 5分野10小単元
・小数：小数のしくみ／小数のたし算・ひき算
・がい数：四捨五入とがい数／がい数で見積もる
・分数：真分数・仮分数・帯分数／同じ分母の分数の計算
・面積：長方形・正方形の面積／組み合わせた形の面積
・図形：垂直と平行／いろいろな四角形
各小単元：説明3ページ、いっしょに考える、練習6問、テスト10問。
合計：練習60問＋テスト100問＝160問。

【更新方法】
1. 現在公開しているアプリのすべてのファイルをバックアップする。
2. ZIPを展開する。このZIPには4ファイルがあり、フォルダーはありません。
3. index.html を、現在の index.html と置き換える。
4. app-v424.js と style-v424.css を index.html と同じフォルダーへ追加する。
5. 以前の app-vXXX.js と style-vXXX.css は削除しない。
6. ブラウザーで再読込。『小学四年 算数 v424』から新しい10小単元へ。
7. 学習者を選んでからテストし、学習記録が保存されるか確認する。

※ v424のZIPだけでは過去の教材は動きません。これまでの既存ファイルが必要です。
※ わかりやすさのため、分数問題は「約分しないで答える」形式を含みます。
※ 音声読み上げは端末の読み上げ機能を利用するため端末環境によって違います。
※ テスト完了時の記録保存は従来の学習者選択・記録保存機能を利用します。
※ 前回の「大きな数・わり算・角・折れ線グラフ」は変更していません。
※ 小学4年の他の単元（立体、計算のきまり、変わり方など）は引き続き点検・補強が必要です。

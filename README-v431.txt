Pono Learning Quest v431｜小学4年生 国語の補強

【追加内容】
・5分野、10小単元
・各小単元に「まなぶ3ページ」「いっしょに考える」「練習6問」「単元テスト10問」
・練習60問＋テスト100問＝160問
・漢字の読み／使い分け、熟語・送り仮名、主語・述語、修飾語・つなぎ言葉、丁寧な言い方、慣用句、段落、理由を添えた文章
・一部単元に自由記述欄と自己チェックを追加（自由記述は自動採点・自動保存しません）
・既存の学習記録形式に合わせて選択問題の結果を保存します（学習者を選んでいる場合）。

【更新手順】
1. 公開中のアプリの全ファイル・学習記録を事前にバックアップする。
2. ZIPを展開する。中身はフォルダーなしの4ファイルです。
3. index.html を公開フォルダーの同名ファイルに上書きする。
4. app-v431.js と style-v431.css を index.html と同じ場所へ追加する。
5. v430以前のファイルは削除しない。
6. 小学4年 国語 v431 の入口を開き、試しに1単元の練習と記録を確認する。

【大切な注意】
・これは追加更新用ZIPです。単体で既存アプリ全体が動作するわけではありません。
・読字や書字の困難がある子にも、音声読み上げ・文字の大きめ表示・時間制限なしで対応します。
・記述式は正解文との完全一致で不正解にせず、見直しのチェック項目を表示します。
・学習記録の保存は既存アプリの学習者選択・保存機能が動いている必要があります。
・この追加は小学4年生の国語の一部を補強するもので、学年配当漢字の全字を網羅したことを意味しません。
・公開環境でのテストは更新後に実施してください。今までの学習記録がある端末で動作を確認します。

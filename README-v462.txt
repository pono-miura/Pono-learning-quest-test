Pono Learning Quest v462｜先生用・みんなの学習一覧
================================================

追加したこと
・この端末に学習記録がある学習者を、まとめて確認する先生用画面。
・今日終了した学習、途中保存、今週の学習計画、見直し日の来た支援目標、先生の6項目確認、最新の学習記録日を表示。
・確認候補、今日取り組んだ子、今週の学習計画がある子で絞り込み。
・先生が一覧の表示名をこの端末に保存可能。子どもの実名でなく記号も使用できます。
・表示名を含めないCSV出力。個別の内容を含むため保存時に確認が必要です。
・v461先生用ホームから開くボタンを追加。既存の記録は読み取り専用です。

更新方法
1. ZIPを展開。
2. index.html を以前の同名ファイルと置き換え。
3. app-v462.js と style-v462.css を同じフォルダーに追加。
4. 以前の app-v***.js と style-v***.css は削除しないでください。
5. v456のバックアップで記録を保存してから更新してください。

重要な注意
・端末内の記録だけを表示します。すべての登録児童や別端末の学習者を自動取得する機能ではありません。
・一覧にない子は、その学習者をトップで選択してから一覧登録してください。
・先生確認は誤操作防止であり、パスワードや本人認証ではありません。
・学習回数と記録件数は異なります。取り組みの有無から障害や習得度を判定しません。
・表示名、学習状況、CSV等を共用端末で扱うときは慎重に管理してください。
・全ての学習記録の保存先は端末内です。クラウド同期は未対応です。
・新しい問題ではなく、先生の管理機能の追加です。

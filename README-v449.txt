Pono Learning Quest v449｜小学4・5年生 漢字395字の思い出し総復習

【今回追加】
・小学4年生202字・5年生193字（計395字）の総復習機能。
・1字ごとに「漢字を隠して思い出す → 読み → 部品 → 文の中で使う」の順番で学習できます。
・これまで作成した395字の部品・言葉の教材を再利用します。新しい配当漢字の追加ではありません。
・一度の学習は3字・5字・10字を選択できます。
・ヒント・間違い・これまでの復習予定を参考に、今日のおすすめを選びます。
・自力で思い出し3問を間違えず解けた場合には、1・3・7・14・30日後へと復習間隔を延ばす目安を表示します。難しい場合は1～2日後の再確認を提案。
・書き取りは必須ではありません。読み上げ、ゆっくり音声、文字拡大、誤答の解き直しにも対応しています。
・以前の学習記録は読み取りのみで、書き換えません。新しい復習履歴は v449 の専用保存領域に保持します。
・v438の「読む・形が分かる・書ける」の個別評価を、選択式問題の結果で上書きしません。

【Androidでの更新】
1. 現在の学習フォルダーをバックアップしてください。
2. ZIPを展開します。
3. index.html を既存の index.html に置き換えます。
4. app-v449.js と style-v449.css を以前のアプリファイルと同じフォルダーへ追加します。
5. 過去の app-v***.js / style-v***.css を削除しないでください。
6. アプリのトップから「395字の思い出し総復習｜v449」を開きます。

【注意】
・漢字を選んで答えられることは、手書きの能力があることを示しません。
・復習の優先順や間隔は学習支援の目安であり、医療・心理検査ではありません。
・学習履歴は現在使っている端末の保存領域にあります。別端末への自動同期はありません。
・アプリの実際の公開環境では更新後の動作確認が必要です。
・Pono独自の説明であり、ミチムラ式の公式教材・唱え文は転載していません。

Pono Learning Quest v453｜今日の漢字・先生の準備と子どもの学習

【更新するファイル】
1. ZIPを展開します。
2. ZIPにある index.html で、使用中の index.html を置き換えます。
3. 同じフォルダーに app-v453.js と style-v453.css を追加します。
4. それまでの app-vxxx.js / style-vxxx.css は削除しないでください。
5. 更新前に使用中フォルダーをバックアップしてください。

【v453でできること】
・先生が小学4年／5年の漢字を選び、3～5字ずつ用意します。
・v452の今週のプランがあれば候補に優先表示します。未作成の場合はv451の候補を使用します。
・子ども用画面では、1字ずつ、大きな表示・音声・部品ヒント・答えを確認します。
・声／部品／文の意味／思い出す練習を自由に切り替えられます。
・疲れた時は答えを見ずに終了することもできます。
・子どもの振り返りと、先生向けの確認画面・CSV出力があります。

【記録の扱い】
・選択中の学習者IDごとに「pono453-quick:学習者ID」のキーで端末内に保存します。
・保存するのは取り組んだ漢字・方法・振り返り・ヒント・日付です。
・子どもの自由記述や氏名は保存しません。CSVにも氏名を含めません。
・v438の読み／形／書字の個別評価、v449の復習予定、v452の週間プランは変更しません。
・選択問題や振り返りの結果を「書ける」という評価へ変換しません。
・端末を変えると学習記録は自動的に移りません。
・先生用の表示はパスワードで保護されているわけではありません。共用端末での取り扱いに注意してください。

【必要な既存ファイル】
app-v449.js（漢字395字データ）、app-v450.js、app-v451.js、app-v452.jsなど、これまでの関連ファイルを同じフォルダーに残してください。

【画面テスト】
小4／小5の切り替え、週間プランの優先表示、漢字の選び直し、音声設定、子ども用3字の練習と中断、ヒント・採点でない振り返り、先生用画面、CSV、学習者別保存、旧データ非変更をローカルのテスト画面で確認しました。実際の公開先での動作は更新後の確認が必要です。

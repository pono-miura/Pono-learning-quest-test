Pono Learning Quest v436 — 更新方法（Android対応）

1. このZIPを解凍します。
2. 今までのアプリのファイルが置いてある場所の index.html を、このZIPの index.html で置き換えます。
3. app-v436.js と style-v436.css を同じフォルダーに追加します。
4. app-v435.js や style-v435.css など、これまでのファイルは削除しないでください。
5. アプリを開き「似た字・部品を見分けよう｜v436」を選びます。

追加内容
・v435の小学4年34字／小学5年39字、合計73字を使い、2つの部品を順番に選んで組み立てます。
・似た漢字の見分け：小学4年12問／小学5年12問、合計24問。
・見本を見る・音声でヒントを聞く・誤答後の再挑戦は自由で、書き取りは必須ではありません。
・練習済みかどうかは学習者ごとに端末内に保存します（サーバーとの同期は行いません）。

注記
・これは漢字の構造認識と識別の自主練習です。書字能力そのものを自動判定しません。
・公式ミチムラ式の唱え文やカードを転載したものではありません。Ponoオリジナルの教材です。
・公開環境での読み込みは更新後に確認してください。
・更新前に既存ファイルのバックアップを取ってください。

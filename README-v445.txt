Pono Learning Quest v445（Android向け更新）

今回：小学4年生50語、小学5年生50語、計100語。すべてv441で追加した漢字を、言葉と文脈の中で練習する教材です。新規漢字100字を追加した意味ではありません。

各語2種類の選択問題：①文に合う言葉を選ぶ、②言葉の意味を選ぶ（計200問）。③自分の文を口頭・心の中・任意の文字入力で考える活動。書く練習は必須ではありません。読み上げ、ゆっくり音声、文字サイズ、3・5語ずつの練習に対応。

更新手順：
1. 現在のPono Learning Questのフォルダーをコピーしてバックアップ。
2. ZIPを展開する。
3. index.htmlを前のファイルと置き換える。
4. app-v445.jsとstyle-v445.cssを同じフォルダーに追加する。
5. 以前のJS・CSSファイルは削除しない。
6. Pono Learning Questのトップ画面から「漢字を文で使う練習 v445」を開く。

注意：端末内のlocalStorageで学習者ごとに練習状況を記録します。別端末とは自動同期されません。入力した自由文は記録しません。選択問題の正解は「書ける」を意味しません。v438の読み・形・書字の個別評価は別の記録として残ります。

同じ漢字でも言葉の中では読み方が変わる場合があります。教材ではそれぞれの言葉の読み方を示しています。例文・説明文はPono独自に作成し、ミチムラ式の公式の唱え文は転載していません。

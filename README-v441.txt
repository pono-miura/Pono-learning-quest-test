Pono Learning Quest v441 — Android更新用

今回の内容：小学4年生の新しい50字、小学5年生の新しい50字、合計100字を「言葉にして部品を覚える」学習に追加しました。
以前の73字と重複はなく、部品学習は合計173字です。配当漢字395字の全字一覧はv434のまま残ります。

方法：
1. ZIPを展開する。
2. index.htmlは上書きして置き換える。
3. app-v441.js と style-v441.css を以前の教材フォルダーと同じ場所に追加する。
4. 古い app-v***.js、style-v***.css を削除しない。念のため更新前のフォルダーをバックアップする。

学習：1回3字または5字。1字につき「形を見る→読み方を選ぶ→部品を選ぶ→言葉から漢字を思い出す」。書くことは必須ではありません。
「自力で思い出した」「ヒントで思い出した」「もう一度」を別に記録し、復習日を提案します。
学習者ごとの進捗はこの端末のlocalStorageに保存され、他の端末には自動同期されません。
読み上げは端末の音声合成機能に依存します。音声を使わなくても学習できます。
記録されるのは選択結果などで、筆記能力を判定するものではありません。
漢字を言葉と部品で覚える一般的な考え方を参考にした、Pono独自の手がかりです。ミチムラ式の公式唱え文は転載していません。

含まれるファイル：index.html, app-v441.js, style-v441.css, README-v441.txt

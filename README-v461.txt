Pono Learning Quest v461｜先生用ホーム
====================================

今回の追加
・日常でよく使う6つの管理操作を一画面にまとめました。
  ① 学習者と端末の確認（v455）
  ② 今週の学習準備（v452）
  ③ 子ども用の学習（v454）
  ④ 学習記録の確認（v457）
  ⑤ 学校・保護者向けレポート（v458）
  ⑥ バックアップ（v456）
・今日済ませた項目をチェックでき、学習者ごとに端末内へ保存します。
・以前の先生用ボタン（v450〜v460）は折りたたんで残します。
・必要に応じて、復習・個別支援・経過表示へ直接移動できます。
・学習者の選択がない場合と、子ども用画面が使用中の場合は個別の集計を表示しません。

更新方法（Android向けの簡単更新）
1. ZIPを展開する。
2. index.html を従来のものと置き換える。
3. app-v461.js と style-v461.css を同じフォルダーに追加する。
4. 以前の app-v***.js と style-v***.css は削除しない。
5. 学習記録は、更新前にv456のバックアップで保存しておく。

注意
・先生の確認チェックは誤操作を減らす仕組みであり、本人認証やパスワード保護ではありません。
・旧記録や評価は上書きしません。新たに「pono461-flow:<学習者ID>:<日付>」を保存します。
・「今日の学習記録」は複数の既存機能による取り組み履歴の件数です。
  読み書きの習得や学習時間を表すものではありません。
・別端末への自動同期はありません。
・このZIPは更新用なので、初回インストール用の全ファイルは含みません。
・実際の端末とPonoの運用で確認しながらお使いください。

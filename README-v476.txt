Pono Learning Quest v476｜子ども・保護者・Pono管理者 3つの入口

【今回の内容】
・起動すると「子どもの学習」「保護者」「Pono管理者」を選ぶ画面が表示されます。
・子ども：既存のv475 在籍学年→教科→教材のメニューに進みます。
・保護者：以前の「自分の子の学び」画面に進み、今週の学習記録・学校共有画面を確認します。
・管理者：「月間学習報告書」「日々の詳細記録」「先生用管理ホーム」「時間割」「試用チェック」「バックアップ」に進めます。
・学校への出席扱いの申請・通所報告書は別のままで、アプリの月間学習報告書は補足資料です。
・教材、解答、採点、学習履歴、在籍学年、既存機能は変更しません。

【GitHubに登録するもの】
1. 先に、既存の学習記録をv456でバックアップします。
2. このZIPを解凍します。
3. index.html を既存の index.html に上書きします。
4. app-v476.js と style-v476.css をリポジトリ直下に追加します。
5. 過去のapp-v***.js/style-v***.cssは消さないでください。
6. 公開URLを再読み込みして「Pono Learning Quest v476」の3入口を確認してください。

【試験用としての重要な制限】
・役割を選ぶ画面はログイン・認証ではありません。保護者・管理者用の閲覧制限は未実装です。
・保護者や管理者が見られるのは選択中の端末の記録です。異なる端末の記録は自動で集まりません。
・管理画面を実際の子どもたちに公開する前に、認証・権限分離・クラウド同期が必要です。
・試験では仮IDのみを利用し、氏名・診断名などの機微情報を登録しないでください。
・パソコン、タブレット、スマートフォンでレイアウトが切り替わりますが、実機検証は端末ごとに必要です。

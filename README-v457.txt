Pono Learning Quest v457：先生用・学習状況のまとめ
=================================================

【更新方法（Android向け簡単更新）】
1. 念のため今のフォルダーと学習記録をバックアップする。
2. ZIPファイルを展開する。
3. index.html をこれまでのフォルダーの同名ファイルに置き換える。
4. app-v457.js / style-v457.css を同じフォルダーに追加する。
5. 他のバージョンの JS・CSS ファイルは削除しない。
6. アプリを開き直し、トップの「先生用｜学習状況のまとめ v457」を開く。

【今回できること】
- 選択中の学習者の記録だけを集計（学習者未選択時は集計を表示しない）
- 小学4年／5年／両学年を切り替えて確認
- 直近7日／30日／全期間の取り組み状況を確認
- v451・v452・v453・v454の学習・観察記録を集計
- v438の読み・形・書字の確認記録を、練習回数と分けて表示
- v449の復習予定などから次の漢字の候補を表示
- 先生用の概要文をコピー、期間内の取り組みをCSV保存
- v452（週間プラン）／v454（子どもの学習）／v456（バックアップ）へ移動

【注意】
- これは記録の整理・閲覧機能です。既存データを変更しません。
- 「練習した」「確認した」「書ける」は異なる意味です。推測で能力判定しません。
- 期間の切替は学習・観察イベントに適用されます。
  読み・形・書字の確認状態は現時点の保存内容を表示します。
- 各イベント記録は異なる教材にそれぞれ保存されているため、
  同じ漢字を複数の機能で学んだ場合は別々の記録として数えます。
- 学習者名やIDはCSVとコピー用まとめ文に含めませんが、
  学習内容や共有状況によって本人が推測される場合があります。
- 先生用の画面にはパスワード保護がありません。
  共用端末では学習後に画面を閉じ、端末をロックしてください。
- データは同じ端末・同じブラウザーの保存領域を読み取ります。
  別端末との自動同期はありません。v456で定期的にバックアップしてください。
- このZIPは既存のv456までのファイルをすべて同梱するものではありません。

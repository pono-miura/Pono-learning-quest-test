Pono Learning Quest v477 — 学年別に教材が見つからない不具合の修正

原因:
v475の新しいメニューは、トップページに後から追加した教材カードだけを検索していました。
国語1〜6年・算数などの旧来教材は、教科を選んだ後に画面へ生成される方式のため、
「この組み合わせに一致する教材は見つかりませんでした」と誤表示していました。
教材は削除されていません。

更新（v476が反映されたGitHubのトップ階層）:
1. 更新前に先生用のバックアップ機能(v456)で学習記録を保存。
2. ZIPを展開する。
3. index.htmlを上書きし、app-v477.js、style-v477.cssを追加。
4. 過去のapp-v***.js / style-v***.cssは削除しない。
5. 公開ページを再読み込みする（キャッシュが残る場合はページを再読み込み）。

確認手順:
1. 子どもの学習 → 小学6年 → 国語 を選ぶ。
2. 以前は空だったところから、旧来の国語単元一覧が開く。
3. 単元を選び、問題と戻るボタンが機能することを確認。
4. 他の学年・教科も確認（教材の有無には違いがあります）。
5. トップに戻り保護者・管理者の画面を確認。

挙動:
・以前の単元一覧を開くボタンを全学年・全教科の単元選択画面に追加。
・v475で「対応教材を確認」となっていた教科は、直接旧来の単元一覧を表示。
・元の単元一覧を表示中は、学年と教科のメニューに戻るボタンを追加。
・既存の学習問題、回答、採点、履歴、ID、保護者・管理者機能は変更しない。
・出席扱いの通所報告書と、学習アプリの月間学習報告書は別々のまま。

注意:
・教材が存在しても旧来の一覧が一部未整備である学年・教科は引き続き確認が必要です。
・実名や個人情報を登録しない試用段階です。保護者・管理者のパスワード認証、端末間の自動同期は未整備。
・端末固有の音声再生や実際の問題の全件動作は、更新後の実機確認が必要です。

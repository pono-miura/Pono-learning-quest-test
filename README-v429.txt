Pono Learning Quest v429 - 小学5年 算数 仕上げ・総復習

追加：5分野・10小単元、練習60問、テスト100問、計160問。
速さ／比例／角柱と円柱／分数と小数／総復習 2コース

【更新手順】
1. 公開中アプリの全ファイルと学習記録をバックアップ。
2. このZIPを展開。
3. index.html を既存の index.html に上書き。
4. app-v429.js と style-v429.css を同じフォルダーに追加。
5. 以前の app-v***.js と style-v***.css は削除しないでください。
6. スマホのブラウザーで更新し、小学5年 算数 v429 を開いて動作確認。

【注意】
このZIPは更新用で、単体ではアプリ全体は動きません。
学習記録は旧方式を利用します。学習者を選んでいない場合は保存できません。
比例の説明では原点を通る直線に言及しますが、グラフを手描きする場合は方眼紙などを使ってください。

Pono Learning Quest v425（小学4年 算数の補強）

このZIPは更新差分です。単独ではアプリ全体は動きません。

1. 更新前に、公開中のアプリのファイル一式をバックアップしてください。
2. このZIPを展開し、index.html を既存の index.html と置き換えてください。
3. app-v425.js と style-v425.css を、同じフォルダーへ追加してください。
4. v424以前のJS/CSSは削除しないでください。
5. ブラウザーを再読み込みして「小学4年 算数 v425」を確認してください。

計算のきまり／変わり方／小数×整数・÷整数／直方体と立方体／倍の見方・資料整理。

既存の学習記録は上書きせず、学習者が選択されている場合のみこれまでの記録へ追記します。

Pono Learning Quest v439｜漢字の学び方を選ぶ

【更新方法】
1. 事前に旧版一式をバックアップしてください。
2. このZIPの index.html を既存の index.html と置き換えます。
3. app-v439.js と style-v439.css を、index.html と同じフォルダーに追加します。
4. 以前の app-v*.js、style-v*.css は削除しないでください。旧版の各ファイルを参照して動きます。

【追加機能】
小学4年34字／小学5年39字、計73字の既存漢字を使い、
「見て読む」「聞いて選ぶ」「部品で考える」「思い出して選ぶ」の4方法で学習。
学習者ごとの任意設定（字の大きさ・音声速度・好みの方法）、
v437復習予定・v438の読みや形の記録を参照した3問のおすすめ、
練習結果の端末内保存に対応。書字は必須ではありません。

【注意】
- v439の「正しく選んだ」は書けることの判定ではありません。
- 自動で学習者の型を決める仕組みではありません。本人が学び方を選べます。
- v434の漢字395字全てに4方法が追加されたわけではありません。
- 音声読み上げは端末・ブラウザーの日本語音声機能に依存します。
- 記録は端末内に保存されます。別端末への同期や自動通知はありません。
- v435の公式ミチムラ式文章は転載していません。Pono独自の説明です。

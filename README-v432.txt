Pono Learning Quest v432（小学5年 国語）

追加内容：5分野・10小単元、練習60問＋テスト100問（計160問）。
漢字・熟語・言葉・敬語・接続語・説明文・物語・資料の読み取り・意見文。
自由記述は自動採点をせず、見直しの観点と例文で本人が確認できます。

更新方法：
1. 更新前に今のサイトフォルダーをバックアップ。
2. ZIPを展開して、index.html を既存フォルダーに上書き。
3. app-v432.js と style-v432.css を同じフォルダーに追加。
4. v431以前の JS/CSS は削除しない（このZIPだけでアプリ全体は動作しません）。
5. 公開後、5年・国語 v432 の入口から説明・練習・テスト・学習記録を確認。

学習記録：既存の profile / records / save が使える場合、既存記録に追記。
公開環境で記録保存できない場合は学習者選択とブラウザ側の保存設定を確認してください。

※ 授業で使用する際は実際の音声再生と配信環境での動作をご確認ください。
※ 漢字の全学年配当字を網羅した教材ではなく、補強用です。

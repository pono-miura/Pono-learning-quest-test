Pono Learning Quest v467｜読み上げの速さ・停止ボタン

【追加内容】
「📖 1文ずつ」を開いた後に、次の操作ができます。
①「🐢 ゆっくり」「♪ ふつう」から、聞きやすい速さを選ぶ
②「🔊 この文を聞く」で、その1文だけを読み上げる
③「■ 音を止める」で、途中で読み上げを止める
④「まえの文」「つぎの文」へ移動すると、前の文の読み上げは止まる
※勝手に次の文に進んだり、次の文が自動で読み上げられたりはしません。

【更新するファイル】
1. GitHubの Pono-learning-quest-test を開く
2. index.html を、ZIP内の index.html で上書きする
3. app-v467.js と style-v467.css を、同じフォルダに追加する
4. 古い app-v***.js と style-v***.css は削除しない
5. 公開したアプリの「📖 1文ずつ」を押し、速さの選択が出るか確認する

【大切なこと】
・更新前に、v456のバックアップ機能で学習記録を保存してください。
・読み上げはスマートフォン/ブラウザーの音声機能に依存し、端末によっては使えない場合があります。
・速さ設定のみ、選択中の学習者IDごとに現在の端末内へ保存します。体験モードでは保存しません。
・問題文、回答内容、採点、学習記録、v465の文字表示設定は変更しません。
・他端末への自動同期は行いません。
・今回の追加は、v466の「📖 1文ずつ」画面のみに対応しています。

【反映確認】
漢字問題画面 → 「📖 1文ずつ」 → 「🐢 ゆっくり」「♪ ふつう」のボタンが出れば、v467が読み込まれています。

■ 動作確認
1. 読み上げボタンを押す → 全文表示、黄色は付かない状態。
2. 「▶ 読み上げる」→ 最初の文だけ黄色になる。
3. 次の文が読み上げられる → 前の文の黄色が消え、次の文のみ黄色。
4. 「■ 音を止める」→ 黄色が消える。
5. 「問題にもどる」→ 元の問題と回答を保持。

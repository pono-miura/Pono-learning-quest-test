Pono Learning Quest v454｜先生から子どもへ 画面の受け渡し
===============================================
更新内容
・先生が今日の漢字を3字または5字用意する
・週間プラン／復習候補を参考に漢字を提案。漢字検索、入れ替え可能
・子どもに渡すと、以前の評価や先生の記録が表示されない大きな学習画面になる
・音声、部品、意味、思い出しの4つの方法から子どもが選べる
・ヒントや答えを見ながら取り組む。書き取りは必須ではない
・先生に戻し、途中の状態を残して「あとで再開」できる
・ブラウザーを更新しても、同じ学習者であれば途中から再開する
・終了した学習は学習者ごとに別々に保存し、先生画面で集計／CSV出力ができる
・子どもの振り返りと「書ける・書けない」の評価は別に扱う

Androidでの更新方法
1. このZIPを解凍します。
2. これまで使っているPono Learning Questのフォルダーに
   app-v454.js と style-v454.css を追加します。
3. index.html をZIP内の同名ファイルに入れ替えます。
4. 以前の app-v***.js、style-v***.css は絶対に削除しないでください。
5. 既存の学習記録が消えないよう、作業前にフォルダーをバックアップしてください。

必須の以前のファイル
・app-v449.js、app-v451.js など、v453までのファイルをそのまま保存
・v452の週間プランがある場合は優先的に参照

注意
・先生用画面と子ども用画面の切り替えは、パスワード認証やアクセス権管理では
  ありません。共用端末の個人情報は、端末のロックなど別の方法でも保護してください。
・学習記録は使用端末のブラウザー内のlocalStorageに保存されます。
  別の端末に自動同期されません。履歴の削除などで失われることがあります。
・学習者を切り替える際は、子ども用画面を終了し、正しい学習者を選んでください。
・途中の学習は一時保存できますが、新しい学習を始めると以前の未完了部分は
  置き換えられます。完了・終了済みの記録は残ります。
・CSVは選択中の学習者のみです。名前は含まれませんが、取り扱いにご注意ください。
・振り返りは学習過程の記録であり、読字・書字の能力判定ではありません。
・デモ画面で動作を確認しました。実際の公開環境でも更新後に確認してください。
